# Plant Metrics Mold Management

Unified EAM platform with specialized global mold management, built from an
REA-driven analysis of the COAST Systems mold management platform.

Current phase: **Phase 1 — reference analysis.** The public front-end pass is done
(`research/REA_FINDINGS_COAST.md`); authenticated behaviour is out of scope
because COAST is a third party. See `research/` for environment status, scope and coverage gaps.
No application code exists yet; implementation starts only after Phase 2 approval.

Phase 2 product specification (v0.2, decisions recorded; awaiting approval to build): `docs/PHASE2_PRODUCT_SPEC.md`.
